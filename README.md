# macOS command reference

Searchable page of stock macOS commands plus a few worth installing.

**Source:** https://github.com/yegge/macos-command-reference

## Run it locally

Open `index.html` in a browser. Design-system CSS is loaded from `https://yegge.org/assets/yegge-design.css`.

- `/` focuses search
- `Esc` clears search
- Copy button on every example

## Publish

This repo is the source of truth. To put it on a public URL:

1. Vercel: import `yegge/macos-command-reference` (framework: Other / static).
2. GitHub Pages: Settings → Pages → Deploy from branch `main` / root.
3. grok.me: that host is Grok Build only. Open this project in Grok Build and use **Publish** there. There is no API from this chat to `*.grok.me`.
